# 银河小战士 · 3D 星际射击

一个原创的 3D 星际射击小游戏，专门给手机和平板设计，用浏览器打开就能玩，不需要安装。

## 怎么玩

- 👆 手指在屏幕上任意位置拖动，驾驶飞船上下左右飞
- 🔫 飞船会自动锁定敌人、自动开火
- 💥 点右下角的大按钮放大招，清掉全屏的子弹
- 🎁 吃掉发光宝石：金色＝火力升级，蓝色＝护盾，橙色＝炸弹，粉色＝爱心
- 👾 每 5 波会出现一个大 Boss「机械魔王」

电脑上也可以玩：方向键或 WASD 移动，空格放大招，P 暂停。

## 本地运行

游戏是纯静态网页，没有构建步骤。在仓库目录下开一个静态服务器即可：

```bash
python3 -m http.server 8000
# 然后打开 http://localhost:8000
```

## 技术说明

- 3D 画面用 [Three.js](https://threejs.org/)（已放在 `vendor/` 里，MIT 许可），带辉光后期处理
- 所有模型都是用代码拼出来的，所有音效和音乐都是用 WebAudio 现场合成的，没有任何外部素材
- 画面卡顿时会自动降低画质，保证流畅
